# 📊 Análise de Vendas com Python e Pandas

Projeto desenvolvido com o objetivo de realizar uma análise de dados de vendas utilizando **Python**, com foco principalmente na biblioteca **Pandas**.

A base de dados utilizada foi obtida através do **Kaggle** e passou por um processo de tratamento antes de ser utilizada nas análises.

O projeto busca transformar dados brutos de vendas em informações que possam auxiliar na compreensão do desempenho de produtos, vendedores e faturamento ao longo do tempo.

---

## 🎯 Objetivo do Projeto

O principal objetivo deste projeto é aplicar conceitos de **Análise de Dados com Python**, utilizando uma base de vendas para extrair informações relevantes através da manipulação e agregação dos dados.

Entre as análises realizadas estão:

- Quantidade total de produtos vendidos;
- Faturamento ao longo dos meses;
- Faturamento dentro de períodos específicos;
- Identificação do vendedor com maior faturamento em cada mês;
- Agrupamento e agregação de dados utilizando Pandas;
- Manipulação de datas;
- Tratamento e organização dos dados.

---

## 🛠️ Tecnologias e Bibliotecas

O projeto foi desenvolvido utilizando:

- **Python**
- **Pandas**
- **CSV**

A principal biblioteca utilizada no projeto é o **Pandas**, responsável pela leitura, tratamento, agrupamento, filtragem e análise dos dados.
